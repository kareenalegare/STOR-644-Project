# Report Folder

This folder contains written reports for the STOR 664 group project. 

Part 1 report for the course project includes:

- Introduction and motivation

- Description of the Pokémon dataset

- Exploratory data analysis (EDA)

- Discussion of data limitations

- Proposed analysis plan and null hypotheses for Part 2.

Part 2 report for the course project includes:

- Individual and joint F-tests for hypothesis we proposed

- 95% confidence intervals for each coefficient appearing in our hypotheses

- Visual analysis of model fit and assumptions

- A consolidated table of all hypothesis tests and written discussions
